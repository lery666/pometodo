## 应用代码

PomeTodo 的待办列表、部分表单、图标和样式由本地 sltool 待办模块迁入，再形成独立 React + Tauri 客户端。迁入时有源文件路径、哈希及协作记录，能够确认直接来源。

2026-09-09，作者明确确认：sltool 中的待办模块本来就是自己编写的代码。因此，该模块迁入 PomeTodo 属于复用作者自己的代码，不再以 sltool 整体项目的最初来源不明作为待办代码的开源阻碍。

作者已委托维护方负责开源方案，2026-09-09 本次选择 GPL-3.0-only。第三方依赖和资源仍按各自许可处理，不因待办代码由作者自写而改变。sltool 本地元数据中的 MIT 字样不改变 PomeTodo 本次自有代码的许可选择。

## 字体与图片

来源开发目录曾保存四个 PingFang TTF 文件，字体内嵌声明包含禁止分发要求。当前应用构建已禁用 publicDir 并使用系统字体，公开源码候选需同时排除字体文件与携带它们的旧 Git 历史。

不删除或重写原开发仓库历史。首次公开使用经过核验的当前文件快照，不直接推送来源仓库的历史。快照仍须保留应有的第三方声明，排除历史并不能消除代码本身的许可义务。

测试截图由仓库中的生成脚本使用虚构文字绘制。产品标志与代码许可分别说明，不把第三方组件的许可证自动套用于品牌标志。

## 依赖

前端依赖锁定于 pnpm-lock.yaml；核心存储与桌面原生依赖分别锁定于两个 Cargo.lock。源码引用的外部依赖应按其各自许可证获取和使用。

依赖许可清单见 [DEPENDENCIES.md](DEPENDENCIES.md)。该清单记录所检查版本的元数据，不替代各组件完整许可、版权声明及二进制分发时的义务。
